# 微信公众号内容分段背景图生成规范

## 提示词结构

为每个页面背景明确以下字段：

1. `Asset type`：微信公众号长图的第几段背景。
2. `Primary request`：该段表达的核心概念。
3. `Scene/backdrop`：纸张、展厅、工作室或画廊氛围。
4. `Subject`：灯、相机、杯、植物、音箱等器物。
5. `Style/medium`：写实静物与克制的生成式声波线条。
6. `Composition/framing`：明确 HTML 文字区和留白占比。
7. `Lighting/mood`：柔和、理性、温暖、触感明确。
8. `Color palette`：暖象牙、炭黑、IF.Link 橙。
9. `Constraints`：禁止文字、数字、Logo、二维码、表格、UI 和水印。

## 负空间策略

- 封面：左侧约 60% 与中央约 55% 保持干净，器物放右下。
- 奖项：中央约 68% 保持空白，器物限制在上右和边缘。
- 权益：上方约 75% 与左侧约 68% 保持空白。
- 时间与 CTA：左侧约 72% 保持干净，器物与声波贴右侧边缘。

将留白写成可测量的比例，不只写“留一些空白”。

## 连续性

多段背景统一：

- 同一种暖象牙纸纹；
- 同一种橙色细声波；
- 奶油色陶瓷器物与黑色台座；
- 柔和博物馆日光；
- 克制、非科技 UI 的视觉语言。

器物可以变化，但材质、光线、声波笔触和视角不能每页重启一套风格。

## 生成后检查

- 是否出现伪文字、伪 Logo、数字或二维码形状；
- 相机、台灯、杯把和植物叶片是否畸变；
- 文字预留区是否真的干净；
- 声波是否进入正文区；
- 页面边缘是否留有足够裁切余量；
- 与上一段背景的纸色和橙色是否一致。

不在背景图中加入任何最终文案。所有信息层由 HTML 完成。
