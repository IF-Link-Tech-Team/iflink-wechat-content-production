# 活动总结与结营回顾

制作活动总结、结营回顾或学习活动复盘推送时读取。这里规定内容优先级与组织方法；配色、字体和具体长度延续本次活动已确认的视觉，不复制某一篇案例的数字或版式。

需要字号起点时，读取 [brand-and-layout.md](brand-and-layout.md) 中“活动总结终稿的字号实测参考”：包含按 390px 图片显示宽度换算的层级、行距与边距，并区分位图可见字高、重建字号和阅读优化建议。

## 1. 内容重心与素材

让读者看见谁参与了、经历了什么、做出了什么，以及参与者自己的感受。数据与课程安排提供背景，真实参与过程、成果、感言和后续方向是重心。

先读取活动信息、课程安排、统计来源、作品及反馈。缺失时明确指出缺口，不为填满模板编造作品、引文或成效。可从以下结构取舍，不要求每篇使用完全相同的章节：

| 模块 | 内容 | 呈现方式 |
|---|---|---|
| 活动概况 | 时间、主办方、参与对象与活动目的 | 简洁导语，避免重复叠加“活动介绍”等空标题 |
| 规模与参与 | 报名、覆盖范围、参与方式与持续过程 | 少量关键数据卡＋单位、口径＋过程短文 |
| 课程与亮点 | 各阶段做了什么、解决什么问题、获得什么启发 | 课程表、步骤或适度时间轴；海报／现场图配内容提炼 |
| 实际成果 | 作品总览、代表作品及使用场景 | 分类概览或词云＋案例标题、用途说明、截图 |
| 真实反馈 | 参与者描述的收获、困难和变化 | 按主题归纳、署名摘录，必要时辅以原始反馈图 |
| 后续方向 | 如何继续学习、交流和参与 | 简洁展望、感谢与清晰入口 |

课程不要只列工具或技术术语，说明学习者能够完成什么。例如将“搜索与核验”解释为“学会用 AI 查找信息，并核对来源，避免把编造的内容当成事实”。措辞应忠于真实课程，不自行增加教学成效。

直播详情解释内容与收获，不重复罗列海报已有信息。日期已在海报区清晰展示时，可用编号标题和宽栏正文，避免重复日期栏挤窄长段落。短内容仍可使用时间轴，不一律取消日期。

## 2. 数据与主体措辞

- 分清报名人数、独立参与人数、提交次数、作品数和占比；核对统计对象、时间范围及跨表去重方式。不得把累计次数直接称为人数。
- 数据卡先突出数字与单位，附必要口径。对外可以使用经确认的量级表达，但保留原始准确数据；不能为了好看自行约数、改写比例或补造数字。
- 数字被修改或删除时，同步检查标题、正文、图表和说明。某指标从终稿消失，并不能证明其错误原因已查明。
- 优先从参与者角度写成果，例如“学员产出”，而非只写“我们收到”；使用这种措辞前确认作品确为参与者产出。

## 3. 作品与线上现场感

- 用整体概览表达成果广度，用代表案例解释实际价值；不把全部作品名单原样堆到末尾。
- 每个案例包含名称、解决的问题或使用场景、成果说明与真实截图。案例数量由内容差异与篇幅决定，不固定为三个。
- 词云是可选概览，不代替案例；未做词频统计时，字形大小仅表示视觉层级，不声称代表出现频率。
- 海报或作品截图在手机上应看得出关键内容。四张高信息密度海报不要硬挤成一排，可用 2×2 或逐张展示。
- 线上活动可以用课程海报、作品截图和讨论反馈体现参与现场，不为模仿线下总结而填入无关照片。
- 图像中的细节若难以读清，在正文补充核心信息；作品图承担展示和证据作用，不能代替用途解释。

## 4. 感言与编辑归纳

- 先按实际收获分组，再选有内容的原话，避免把所有反馈拼成小字墙。
- 主结论与精选感言直接排成可读文字，原始反馈图可作为补充证据；引文、截图和概括之间有清楚层级。
- 引用保留真实署名及含义，按素材使用要求处理身份；明确区分原话、转述和编辑归纳，不把编辑生成的句子放进学员引号。
- 分组依据实际反馈，不固定为某一次课程的技能分类。没有对应原话时，不为每组形式对称而编造引文。
- 结尾承接前文成果，说明继续学习或交流的方式；避免另起一个网站式口号 hero，或把尚未整理的材料全部压在结尾。

## 5. 活动总结追加验收

- 活动信息与数据有来源，人数、次数、占比口径清楚。
- 过程包含具体行动与阶段收获，课程／直播不只是标题清单。
- 实际作品、用途说明和截图相互对应；反馈原话与编辑归纳可区分。
- 作品与感言在篇幅中得到充分展开，正文、数据卡、图片与引文有疏密变化。
- 后续入口与活动自然衔接，关键图片、反馈摘录和二维码在手机上可用。

内容审核与图片导出不等于完成发布验收。交付供上传后，仍需在公众号实际预览中核对标题、封面、正文和二维码；未执行的检查如实列出，不推断已经完成。此 Skill 本身不负责公众号后台发布。
