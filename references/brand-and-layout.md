# IF.Link 微信公众号内容排版基线

手机可读、正文秩序和视觉节奏是通用要求；下列尺寸、字体和暖纸橙色方案是现有模板的起点，不能覆盖项目已确认的活动视觉。

## 1. 画布与安全区

- 新建固定分页模板：`900 × 1800px`；已有连续长图按确认的分段高度制作，统一宽度，不为凑页数拉长或裁短。
- 常用左右安全边距：`68–90px`。
- 常用正文有效宽度：`700–760px`；杂志式窄栏可使用 `560–620px`。
- 保留纵向呼吸空间；信息过多时增加页数，不缩小正文。
- 背景器物尽量限制在右侧 25%–32% 或页面边缘。

## 2. 字体体系

- 中文正文：思源黑体 Variable / Source Han Sans SC。
- 新建中文封面可选宋体、思源宋体；已有活动标题字形优先沿用，不强制改成衬线体。
- 英文与数字：Google Sans Flex 或 Inter Variable。
- 代码、技术标识：JetBrains Mono，仅在确有代码信息时使用。
- 禁止通过 `transform: scaleX()` 或非等比缩放改变中文字形。

以下为既有模板在 900px 画布下的参考值，不是手机可读性的验收阈值：

| 层级 | 建议字号 | 行高 |
|---|---:|---:|
| 封面主标题 | 118–178px | 0.95–1.08 |
| 页面主标题 | 58–82px | 1.08–1.22 |
| 模块标题 | 34–48px | 1.18–1.32 |
| 正文 | 27–32px | 1.55–1.75 |
| 说明与注释 | 21–24px | 1.45–1.65 |
| 关键数字 | 36–56px | 1.0–1.2 |

同级文字保持一致，不因某一段装不下而局部缩小。

按实际显示宽度校准字号：显示字号约等于 `源字号 × 显示宽度 / 图片宽度`。例如 900px 图显示为 390px 宽时，27–32px 正文约等于 11.7–13.9px，可能偏小；应提高对应层级字号并重排，而不是以达到旧模板数值为合格。“比旧版放大一倍”属于相对反馈，不固定成永久字号。

使用模板时先替换并确认字体文件实际加载；不要只声明字体名后依赖系统回退。检查中文、英文、数字与标点的字形和基线。

### 活动总结终稿的字号实测参考

以下来自一份已审核的 900px 宽活动总结长图，对正文、课程行、标题、数据卡和感言等多个区域抽样。以**图片在手机中实际显示为 390 CSS px 宽**作为参考，缩放系数为 `390 / 900 ≈ 0.433`；这不是指定手机型号，也不是设备物理像素或 pt。若手机视口为 390px，但文章容器另有边距，应代入图片实际显示宽度。

只有位图，没有源 HTML：可测的是文字笔画的可见高度，不能精确反推 `font-size`。下表的两列字高分别为原图测量与手机换算，最后一列为换用中文黑体／衬线体及数字字体时的**重建起点**，不是原稿 CSS 的确定值。字体、字重、字形和抗锯齿都会影响结果。

| 层级与取样对象 | 原图可见字高（900px 图） | 手机可见字高（图宽 390px） | 可编辑重建字号起点：900px 画布 → 手机等效字号 |
|---|---:|---:|---|
| 章节主标题、成果区大标题 | 约 65px | 约 28px | 68–72px → 约 29–31px |
| 二级标题：直播主题、作品名称、收获小标题 | 约 37–41px | 约 16–18px | 40–46px → 约 17–20px |
| 正文：活动介绍、作品说明、反馈归纳 | 主要为 29–30px，个别混排行约 32px | 主要为 12.6–13px | 32–34px → 约 14–15px |
| 精选感言、课程表文字、数据卡名称 | 约 29px | 约 12.6px | 32–34px → 约 14–15px，与正文同级 |
| 数据卡大数字 | 约 62px | 约 27px | 80–88px → 约 35–38px；数字字面高度占字号比例不同，需试排 |
| 章节胶囊标签、案例编号提示 | 约 20–24px | 约 9–10px | 22–28px → 约 10–12px，仅作辅助导航 |
| 数据卡口径说明 | 约 21px | 约 9px | 约 24px → 约 10px；这是终稿现状，不是关键说明的推荐最小值 |
| 原始反馈截图内的小字 | 约 15–16px | 约 6.5–7px | 不作为正文或注释字号参考；核心内容须另排可读摘录 |

- 主封面的艺术字已在原图中倾斜、描边并进行图形化处理，不将其整体包围框高度当成字号；沿用确认素材或单独做视觉匹配。
- 词云最大主题文字的可见高度约 65px，可与章节标题建立联系；其余词语按视觉层级排，不为复刻某个词云强设一套正文字号。
- 连续正文相邻行的起点间距实测约 49–52px，缩放后约 21–23px；以 32–34px 源字号重建，可先试约 `1.5–1.65` 行高。段落间距另外设置，不把段间停顿计入行高。
- 原图主要正文左右各留约 70px，正文宽约 760px；显示为 390px 宽时，对应左右各约 30px、正文宽约 329px。估算字号时同时保留列宽，避免只放大字却将正文挤窄。
- 同一张图显示为 375px／414px 宽时，表中手机端数值分别再乘 `375/390 ≈ 0.962`／`414/390 ≈ 1.062`。比较时使用相同的图片实际显示宽度。

复用这种活动总结版式时，以上层级比旧模板的统一建议值更贴近该终稿，但终稿正文的手机等效字号仍约 14–15px，不应宣称它已经达到 16–18px。若新稿希望正文达到 16–18px，可从 900px 画布的约 37–42px 试排（按 390px 图宽换算）；这是阅读优化建议，不是终稿测量结果。相应增加纵向空间，并重新检查换行、行高和图片比例，不机械替换所有层级。

## 3. 首屏经验

以下位置经验来自“万物开口计划”等宣传海报。其他活动优先延续确认的封面，不套入案例中的活动名、合作方或位置。

- “万物开口计划”等活动名使用大号中文衬线体。
- 主标题不要贴近页面顶部；让上方、标题内部和标题下方形成连续留白。
- 将副标题与口号放在主标题下方左对齐。
- 将 `IF.Link × MossLand` 和“联合发起”放在口号下方，而不是挤在顶栏。
- 以可见墨迹边界做左对齐；“万”“开”等字形左侧留白可能产生光学错位，可做小幅负边距，但除非用户确认，不必为了机械对齐破坏字距。
- 将情景带入语句放到首屏海报下方，作为独立、居中的下一段落。
- 封面不放页码，除非用户明确要求。

## 4. 内容页经验

- 连续正文默认两端对齐（HTML 可用 `text-align: justify; text-align-last: start`），保持左右安全边界；不要全局强制短标题、引文、词云或手动语义分行两端拉满。
- 叙事段落可按语义换行，长说明分段；用行距、段距和适量留白形成停顿，不让每段长度与容器完全相同。
- 主封面可以保留醒目的活动标题；普通正文标题适度，不把口号做成反复出现的网站式 hero。删除重复的章节标签与空泛标题层级。
- 根据内容混用直接排字、数据卡、表格、引文、图片和分隔线。深色背景可直接放浅色正文，不为每段添加浅底卡片。
- 背景、正文和图片保持明确对比；避免贯穿全宽的异色横条无故割裂画面。局部卡片与有意设计的页间呼吸区仍可保留。
- 奖项页优先放大奖项名称、名额和金额；说明文字次之。
- 奖项数量不能过小，手机端至少与正文同级或更大。
- 奖项说明优先使用结构清楚的名词性短语，保持每行句式平行；用户提供最终版本时逐字采用，不再自行润色。
- 产品介绍使用浅色卡片或留白区，不在浅色主题中突然插入纯黑大块。
- 时间轴的圆点中心必须与轴线中心一致。
- 正文有背景干扰时，先移动内容或调整背景；只有局部需要时才使用承托层。
- 承托层应服务于阅读，不应形成覆盖整页的白色大托盘。

### 中文引号

- 使用中文弯引号 `“` 与 `”`，避免西文字体把引号渲染成两条粗斜线。
- 装饰性引号使用中文衬线字体，如 `"Songti SC", "STSong", "Source Han Serif SC", serif`。
- 当引号承担段落装饰时，上引号独立位于段落上方，下引号独立位于段落下方；不要放在第一句句头或最后一句句尾。
- 修改引号时保留用户已确认的正文行数、断句和强调色，不借机重新流排。

## 5. Bento 与非 Bento

### Bento

适合奖项、权益、步骤等高结构信息。控制卡片数量与密度；每个卡片只表达一个主要结论。

### 非 Bento

适合较长正文和叙事。用分隔线、序号、窄栏和大留白建立节奏，不把所有信息装进圆角卡片。

存在两个版本时，共享已确认的字体、正文最小字号、Logo 尺寸规则、二维码规则、背景色和强调色，不要求每篇制作两个版本。

## 6. 色彩与对比

先使用本次已确认的活动配色。以下暖纸与橙色用于相应模板；蓝色星空等其他活动方向也应保持自身一致性，不混入不相关的器物或声波。

- 暖象牙纸色：约 `#F4EBDD` / `#F6F0E7`。
- 炭黑正文：约 `#151515` / `#25211E`。
- IF.Link 橙：约 `#E64A13` / `#E94B14`。
- 说明文字仍使用深灰；避免在手机端使用过浅的米灰色正文。
- 装饰声波和橙色线条不能穿过正文。
