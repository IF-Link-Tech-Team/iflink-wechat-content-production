# 渲染、手机验收与导出

## 1. 浏览器检查

每次前端修改后，至少截图检查封面、信息最密集页和末页。

使用目标锚点只显示一个分段，再截取明确坐标。以下为 900×1800 固定模板示例；不同段高按实际尺寸设置 clip：

```text
http://127.0.0.1:PORT/index.html?v=REVISION#capture-5
clip: { x: 0, y: 0, width: 900, height: 1800 }
```

使用查询参数刷新缓存，避免旧 Logo 或旧 CSS 留在截图中。

不要依赖 `fullPage` 截图拼接固定分页。部分浏览器会在哈希目标、固定高度或背景图条件下重复页面。直接使用对应分段尺寸的 clip。

导航到目标锚点后等待字体、背景和 iframe 稳定，再截图。连续切换页面时立即截图可能捕获旧布局、重复内容或错误 iframe；必要时等待约 `300–600ms`，但仍以固定 clip 为准。

## 2. 图片格式陷阱

某些截图接口返回 JPEG 字节，即使保存路径后缀是 `.png`。拼接前检查：

```bash
identify output/page-5.png
```

若实际为 JPEG，先转码：

```bash
magick output/page-5.png output/page-5-real.png
mv output/page-5-real.png output/page-5.png
```

## 3. 手机端检查

按实际页数生成 contact sheet，可用约 216px 宽缩略图检查整体节奏；再按目标手机实际显示宽度（如 390px）检查阅读效果，不把缩略图当字号合格线。检查：

- 正文是否仍可辨认；
- 页面层级是否一致；
- 是否有过大的空洞或过密区域；
- Logo、金额、名额是否过小；
- 背景是否穿过正文；
- 首屏标题是否过高、过满或偏离左侧视觉轴；
- 末页 CTA 和二维码是否清楚。
- 连续正文是否两端对齐且没有异常字距；标题、短引文和语义分行是否自然。
- 是否反复使用同一种卡片或网站式 hero；长正文是否被重复日期栏、装饰或不必要容器挤窄。
- 海报与作品截图是否看得清关键内容；原始反馈图之外是否已有可读摘录。

总览、原尺寸和手机实际宽度都要检查。导出预览不等于公众号实际预览；由发布环节在上传后核对标题、封面、正文与二维码，未做的检查不要声称完成。

## 4. 内容与品牌检查

- 文稿数字、日期、人数和金额与源文件一致；
- 报名人数、独立参与人数、提交次数、作品数和占比没有混淆；约数或量级表达有确认依据；
- 文案说明具体用途和结果，原话、转述与编辑归纳可区分；活动总结按 [event-recaps.md](event-recaps.md) 做追加验收；
- 删除项没有在其他版本中残留；
- 两个版本使用同一最终文案；
- Logo 使用最新、官方、高清版本；
- 中文字体没有拉伸；
- 乘号、时间轴圆点和对齐线处于真实视觉中心；
- 二维码可扫描，二维码下标签距离合适；
- 署名人员、组织前缀和顺序正确。
- 对改名类反馈执行全局检索，确认标题、正文、脚注、CTA、二维码 `alt`、两个版式和 Banner 中没有旧术语残留。
- 区分品牌联合锁定与单位罗列：封面 `品牌 A × 品牌 B` 可以表达联合发起；“联合主办”下面若只是罗列单位，默认不用 `×` 充当连接符。
- 奖品改为奖金时，同步检查“奖品/礼品/等值”“元/份”“总值”等相关词，并统一为现金金额、`元/人` 和奖金总额等一致语义。

## 5. 输出检查

交付前确认：

- 所有分页宽度完全一致；
- 使用标准署名 Banner 时尺寸为 `900 × 373px`；活动专属结尾按确认尺寸，无独立 Banner 时不额外追加；
- 完整长图高度等于全部实际分段高度之和，加上独立 Banner 高度（若有）；仅当全部分页为 1800px 且追加标准 Banner 时，使用 `页数 × 1800 + 373px`；
- 完整长图没有重复页、空白条或横向偏移；
- 默认按完整分页拼接，不裁掉页首页尾的留白、纸张底色或呼吸区；“接缝自然”不是自动裁边的授权。
- 首段与末段（包含 Banner 时也检查 Banner）都能完整显示；
- HTML 仍可直接编辑；
- 最终答复给出 HTML、完整长图、关键分页及实际制作的 Banner 的可点击绝对路径。

## 6. 增量渲染与紧急交付

按反馈范围更新产物：

下表的两个版式和 Banner 仅指项目实际存在的产物，不为满足检查清单额外创建。

| 修改类型 | 必须重渲染 |
|---|---|
| 单页文案或排版 | 两个版式的对应分页、完整长图、contact sheet |
| 全局术语或字体 | 所有受影响分页、两个版式完整长图、contact sheet |
| Logo、二维码或合作伙伴 | 出现该素材的分页、完整长图、contact sheet |
| 署名或社交二维码 | 更新 HTML Banner、重新渲染 Banner、所有完整长图 |

用户明确表示即将发布时，保留三项最小验证：目标分页渲染成功、完整长图尺寸正确、旧术语检索为空。随后直接输出图片，不继续做非必要设计探索。
